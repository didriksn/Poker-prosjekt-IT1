# Poker spill
## Enkel poker nettside

En enkel applikasjon laget i IT1 for å simulere et grunnleggende pokerspill i nettleseren. Bruker websockets for å behandle logikken og express med sqlite database for å lagre informasjon.

### 1. Klon prosjektet
```bash
git clone <repo-url>
cd Poker-prosjekt-IT1
```

### 2. Åpne i VS Code
```bash
code .
```

### 3. Kjør prosjektet
Siden dette er en enkel nettside kan du:
- åpne `index.html` direkte i nettleser, eller
- bruke Live Server i VS Code for automatisk oppdatering.
